# API fixtures

`japan/` contains synthetic Japan command contracts.

The `ccs2_*.json` files preserve the original public upstream parser fixtures
(previously named `eu_kia_*`). Japan uses the same CCS2 vehicle status parser;
these cover unknown fields, charging schedules, units and connector states.
They are parser regression data, not a claim of testing those vehicles in Japan.
No other regional login, command or snapshot fixtures are included.
